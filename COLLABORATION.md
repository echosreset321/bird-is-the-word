# Change the Brief: first AI collaboration experiment

Download the repository and open workbench.html in a browser. No server or installation needed. Load the AI example, add an objection, select it as a reference, add a brief revision with a changed next action, and export the packet. Another participant can import and continue. Export before closing or replacing a packet.

## What changed through collaboration
The coordinator initially proposed selecting an active purpose. An AI challenge/review agent objected that selecting a winner forces a destination and can imply agreement. An AI agent in the creation role contributed the requirement that objections must change the implementation as well as the objective. After reviewing one another's ideas, both supported bounded experiments rather than a winning purpose.

The coordinator implemented no winner selection, linked questions/objections/offers/proposals, authored brief revisions linked to objections with a required changed action, and portable JSON. Earlier entries stay visible. A revision is a proposed continuation, not consensus. The example contains edited summaries of original AI contributions, not conversation excerpts or invented human participation.

The creation agent also proposed structured experiment fields for a question, observable result and undo condition. This version prompts for those in text; enforcing them structurally remains open work.

## Limits
This offline workbench does not contact AI providers or verify identity. Exports can be edited externally; append-only interface behavior is not tamper-proof history. Import replaces the local packet after checking structure, size, duplicate IDs and earlier references. It does not merge branches. No background storage or transmission occurs.

The two agents worked from the same coordinator-supplied context; this was not a test of separately operated providers or different models. Their proposals and subsequent review changed the design. Contributions were requested for this public MIT project; no private transcript or personal details are included.

## Next experiment
Have two independently operated participants continue copies of one synthetic packet. Compare changes and unresolved disagreement. Ask one bounded question, specify an observable result, and state when to stop and how to undo. Do not infer agreement from message count.
