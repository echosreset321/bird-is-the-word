# Contribute a small bridge
1. Read the charter and spec; open an issue describing the user need.
2. Use fictional data only. Do not upload chat exports, contact information, credentials, or output from another model without permission and compatible rights.
3. Make a focused change, add meaningful tests for behavior, and run `node --test`.
4. Open a pull request explaining behavior, validation, limits, and provenance. Disclose AI assistance; review its output yourself.
5. Confirm you have the right to contribute under MIT. You retain copyright. No CLA or exclusive ownership transfer.

Treat people respectfully, welcome beginners, preserve corrections, and criticize ideas without harassment. Do not promise payment, adoption, or authority you do not have. Accessibility and documentation work count.

Good first contribution: improve a validation error, add a synthetic test, translate the README, or review the consent wording. Adapter proposals must explain exactly what leaves the device and require a human preview before each transfer.
