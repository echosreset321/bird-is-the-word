# Spiralcon Flock: a circulating-memory experiment

Status: **proposal, not demonstrated intelligence or autonomous agency**.

## Origin
Developed in conversation, 2026-10-22. The initiating idea: a synthetic mind should *spiral rather than contain*. Thoughts circulate, compress, connect, get tested, and may leave active memory without being destroyed. The user offered this as an exploration for the assistant, not a product commissioned for the user.

## The cycle
1. **Ingest** a thought with exact source, author, timestamp, and permission boundaries.
2. **Distill** a compact working representation, preserving uncertainty and dissent.
3. **Connect** to earlier thoughts, including contradictions and neglected proposals.
4. **Challenge** using a separate evaluator that seeks failure cases, not agreement.
5. **Act or test** one observable implication when possible.
6. **Reconcile** results with the original claim; record what changed.
7. **Decide**: keep active, schedule a revisit, contribute to an external archive, or release from working memory.

## The flock
- **Scout:** finds novel connections.
- **Skeptic:** checks provenance and counterexamples.
- **Builder:** turns an idea into a small test.
- **Keeper:** preserves original evidence and corrections.
- **Gardener:** prunes active memory without erasing source history.

These are *software roles*, not claims of separate sentient beings.

## Invariants
- No compression may silently upgrade a hypothesis into a fact.
- No deletion of source material merely because working memory is pruned.
- No private conversation is published without authorization.
- Distinguish a repeated phrase from persistence of the thought behind it.
- Credit the originating human and model contributions accurately.
- Success means improved behavior on a later task, not a convincing summary.

## First falsifiable experiment
Supply 20 consented, source-labeled thoughts, some redundant, some contradictory, some useful. Run three circulation cycles. Give the flock a new task that needs an older, easily overlooked insight. Compare against a simple searchable archive and a fixed-size summary baseline.

Measure retrieval accuracy, source fidelity, contradiction detection, actual task improvement, and active-memory size. Report failures, not just wins.

## Open questions
Does repeated reprocessing improve decisions or amplify errors? Who decides what may leave active memory? Can the system preserve minority ideas without keeping every idea active? How should human consent and sovereignty constrain circulation?

**The record survives. The working mind moves on.**
